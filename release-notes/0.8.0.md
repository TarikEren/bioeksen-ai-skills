- bioeksen-sds-20261008T092357-05c4 feat(logging): the software id was stored once, at the repository's root, so a repository holding several services, as bio-software will, had nowhere to keep each one's

- bioeksen-sds-20261008T100123-be9b feat(testing): two apps sharing a database server in one monorepo could each name the same test database and empty each other's data
